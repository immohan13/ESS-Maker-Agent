Runtime diagnostics (Application Insights)

        
When the agent crashes into [System] - On Error, ESS Maker pulls the real exception from Application Insights and shows it next to the failing prompt — including the topic, action and a fix hint.

How to enable it (one-time, ~5 min)


        

          1Create or pick an Application Insights resource in Azure
          

            In the Azure portal, search for Application Insights. Either pick an existing resource (e.g. one your team already uses for ESS) or click + Create — choose Workspace-based, same region as your Copilot Studio environment.
          

        


        

          2Copy its Connection String
          

            Open the App Insights resource → Overview page → click the Connection String field to copy. It looks like:

            InstrumentationKey=…;IngestionEndpoint=https://…;ApplicationId=…
          

        


        

          3Paste it into Copilot Studio
          

            Open your agent → Settings (gear, top-right) → Advanced → Application Insights. Paste the connection string.

            Toggle on: Enable logging, Log conversation details, Log sensitive properties, Node execution events. Click Save, then Publish the agent.
          

        


        

          4Give ESS Maker read-only access
          

            In the Azure portal, on the same App Insights resource → Configure → API Access → + Create API key. Name it ess-maker-readonly, check Read telemetry, click Generate key. Copy the key — it's shown only once.

            Also copy the Application ID (GUID at the top of the API Access page).
          

        


        

          5Tell ESS Maker about it
          

            Add the two values to the agent config and restart this server, or paste the Connection String below and we'll extract them automatically:

            
            
            
          

        


        
After step 3, send any message to the agent in Copilot Studio's Test pane. Telemetry takes ~2 min to land. Then re-run an eval and click any failed item — the real underlying error will appear at the top of the Insights pane.

Writes a SharePoint knowledge source straight into the live Copilot Studio agent via the Dataverse Web API. Visible in the Knowledge tab in seconds. Each source's description is what the orchestrator uses to decide which to cite — be specific.
